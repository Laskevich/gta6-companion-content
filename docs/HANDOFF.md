# GTA 6 Companion — решения проекта (обновлено 19.11.2026)

Этот файл — источник правды по проекту. Всё, что решили в обсуждении 18–19.11, собрано здесь.

## Продукт
Неофициальное iOS-приложение-компаньон для GTA 6. Стек: SwiftUI + RevenueCat, сборка в Codemagic (мака нет), код и контент на GitHub.

**Позиционирование:** продаём не «знаем коды раньше всех» (крупные сайты опубликовали полный список из 61 чита ещё до релиза), а удобство с геймпадом в руках: трекер испытаний, «План», Live Activity, офлайн, честные статусы.

## Релиз 1.0 (минимум, без которого не выходим)
1. Все 61 чит: статус и минимум один источник в evidence.
2. Испытания с полями `metric` / `target`. Быстрые способы (`method`) — для топ-15, остальные после релиза.
3. Режим ввода (крупные стрелки, экран не гаснет, глифы PS/Xbox), трекер, «План», Live Activity, paywall, seed-копия JSON внутри приложения.
4. Языки интерфейса: en (основной), es (LatAm + Испания), pt-BR, de, it, fr, ru, ja, ko. Контент на этих языках подключается через JSON по мере готовности, пока перевода нет — показывается en.

Всё остальное — следующие апдейты, разделы включаются флагами в `content/manifest.json`.

## Монетизация
- Разовая покупка (non-consumable, RevenueCat), стартовая цена **$2.99**, потом поднимаем («ранняя цена» — только если это правда).
- Бесплатно: полный каталог (название, эффект, статус, условие) + коды 10–15 читов (`free: true`).
- Платно: остальные коды, гайды и быстрые способы, трекер, «План», Live Activity, все будущие разделы.
- Разделение настраивается полем `free` в JSON, без обновления приложения.
- Компромисс, о котором надо знать: публичный JSON на CDN содержит все коды, включая платные. Это сознательно (коды и так публичны), закрываем UX, а не данные.
- Цену в LatAm, возможно, снизить вручную после релиза по конверсии.

## Контент и рейтинг
- Сами в игре не проверяем. Формулировка в приложении и сторе: «Проверено по отчётам игроков и изданий, обновляется ежедневно».
- **green**: ≥2 разных домена-источника, среди них крупное издание или видео; нет конфликтующих данных; код известен; нет достоверных жалоб за 7 дней.
- **yellow**: один источник, ИЛИ расхождения, ИЛИ код ещё не найден, ИЛИ свежие жалобы.
- **red**: опровергнуто или копия кодов GTA 5. «Нет подтверждений 14 дней» → НЕ red, а yellow с пометкой (иначе настоящие редкие секреты станут «фейками»). Red не попадает в приложение, но хранится, чтобы не добавить повторно.
- Жалобы из-за невыполненных условий статус не понижают — улучшаем текст гайда.
- Тексты (`effect`, `unlock.challenge.text`, `steps`, `method`) — только своими словами. Названия, числа, коды — факты.
- Названия читов на других языках (`name.<locale>`) — только официальные из игры. Сами не переводим.
- Проверки в CI: схема, у green минимум 2 домена и крупный источник, нет конфликтов у green, ссылки отвечают.
- **Известный риск seed v1:** Altchar ссылается на PowerPyx, Game Rant источник не указывает. Возможно, оба взяли данные из одного места, независимость не доказана. Первые прогоны агента должны найти третий источник, лучше видео.

## Как добавить гайд (секрет, награду, пасхалку)
1. Запись в `content/guides.json`: `id`, `kind` (secret / collectible / reward / easter_egg / tip), `mode: "story"`, `title`, `summary` (бесплатно, без точного места), `location` и `steps` (платно), `reward`, `free`, `status`, `evidence`, `added` (сегодня), `last_checked`.
2. Тексты своими словами; статус по тем же правилам, что у читов.
3. Первый раз: `manifest.sections.guides.enabled = true`.
4. `python scripts/validate.py` → PR → merge. Приложение подхватит без обновления.
